# 数据库开发课程设计 — 综合管理 Web 系统

基于 **Python Flask + MySQL** 的一体化综合管理系统课程设计项目，包含两套完整的业务系统：

| 系统 | 说明 | 目录 |
| --- | --- | --- |
| 🏨 酒店人事一体化综合管理系统 | 客房管理、入住退房、员工考勤、薪资、报表 | `hotel system/`、`web_app/`、`sql/`、`python/` |
| 🏥 医院门诊管理系统（对标小型 HIS） | 患者档案、挂号、医生排班、处方开具、收费退费 | `hospital_system/` |

两套系统共用一套 MySQL 运行环境与启动方式，各自拥有独立数据库。

---

## ✨ 功能特性

### 酒店人事一体化综合管理系统
- **客房管理**：房态总览、房间维护
- **前台业务**：客户档案、入住登记、退房结算
- **人事管理**：员工档案、考勤记录、请假管理、薪资核算
- **报表中心**：入住统计、收入报表、员工考勤汇总
- **权限控制**：前台 / 人事 / 财务 / 经理多角色

### 医院门诊管理系统（对标小型 HIS 门诊业务）
- **患者档案**：建档、查询、修改、删除（病历号/身份证/电话唯一约束）
- **挂号管理**：按排班挂号、自动收取挂号费、排队号、退号恢复号源
- **医生排班**：号源管理、停诊保护（已有挂号的排班禁止停诊）
- **处方开具**：多药品明细、库存校验、金额自动计算、完整状态机
- **收费退费**：处方收费扣库存、退费恢复库存、退号联动退挂号费
- **报表查询**：今日挂号统计、收费日报、处方明细、医生工作量、CSV 导出

---

## 🛠 技术栈

- **后端**：Python 3.14 + Flask 3.1 + mysql-connector-python
- **数据库**：MySQL 8.4（存储过程 / 视图 / 触发器 / 事务 / 索引）
- **前端**：Jinja2 模板 + 原生 CSS（深色侧栏 + 卡片式管理端布局）
- **工程化**：一键初始化脚本、环境自检脚本、端到端回归验证脚本

## 🚀 快速开始

### 环境要求
- Python 3.10+（`python` 在 PATH 中）
- MySQL 8.x（本机免服务方式，数据目录 `D:\MySQLData`）

### 1. 启动 MySQL
双击 `start_mysql.bat`（Windows），或手动启动 MySQL 服务。默认连接：`root / 123456 / 127.0.0.1:3306`。

### 2. 初始化数据库
```bash
# 酒店系统
cd "hotel system" && python init_database.py
# 医院系统
cd hospital_system && python init_database.py
```

### 3. 启动 Web
```bash
# 酒店系统（端口 5001）
cd web_app && python -m pip install -r requirements.txt && python app.py
# 医院系统（端口 5000）
cd hospital_system/web_app && python -m pip install -r requirements.txt && python app.py
```

浏览器访问：
- 酒店系统：http://127.0.0.1:5001
- 医院系统：http://127.0.0.1:5000

> 两套系统默认端口不同（5000/5001），可同时运行。

## 🔒 数据库设计亮点（医院系统）

- **12 张核心表**：角色、用户、科室、医生、排班、患者、挂号、药品、处方、处方明细、收费、操作日志
- **5 个视图**：今日挂号、医生排班、处方明细、收费日报、医生工作量
- **7 个存储过程**：全部使用事务，保证数据一致性
- **4 个触发器**：业务操作自动写日志、停诊保护
- **约束**：唯一约束（病历号/身份证/电话/排班）、CHECK 约束、高频查询索引
