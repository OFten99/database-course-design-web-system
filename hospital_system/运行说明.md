# 医院门诊管理系统运行说明

对标小型 HIS 门诊业务：患者档案、挂号、医生排班、处方开具、收费退费一体化 Web 后台。
技术栈：Python Flask + MySQL 8.4 + 黑盒测试（禅道用例）+ XMind 需求设计。

## 一、一分钟速览

| 步骤 | 命令 | 说明 |
| --- | --- | --- |
| 1. 启动 MySQL | 双击项目根目录 `start_mysql.bat` | 免服务方式，root / 123456 |
| 2. 初始化数据库 | `python init_database.py` | 一键执行 sql/01~07，可重复运行 |
| 3. 启动 Web | 双击 `run_web.bat` | 浏览器打开 http://127.0.0.1:5000 |
| 4. 登录体验 | admin01 / 123456 | 管理员全权限账号 |

## 三、运行步骤

### 1. 启动 MySQL

双击 `start_mysql.bat`，看到 `[OK] MySQL 已就绪（端口 3306）` 即可。
（本机 MySQL 为免服务方式，开机后需手动运行一次。）

### 2. 初始化数据库

```bash
python init_database.py
```

密码不是 123456 时：

```bash
python init_database.py --user root --password 你的密码
```

看到 `全部脚本执行成功` 即完成（建 12 张表 + 5 视图 + 7 存储过程 + 4 触发器 + 测试数据）。

### 3. 安装依赖并启动 Web

```bash
cd web_app
python -m pip install -r requirements.txt
python app.py
```

或直接双击项目根目录 `run_web.bat`。看到 `Running on http://127.0.0.1:5000` 后，
浏览器打开 **http://127.0.0.1:5000**。

### 4. 测试账号（密码均为 123456）

| 账号 | 角色 | 可测试功能 |
| --- | --- | --- |
| admin01 | 管理员 | 全部功能 |
| reg01 | 挂号员 | 患者建档、挂号、退号、排班 |
| doctor01 | 医生 | 查看挂号、开具处方、患者 |
| cash01 | 收费员 | 收费、退费、药品目录、报表 |

## 四、演示路径（建议按此顺序体验完整业务闭环）

1. **reg01 登录** → 患者档案新增一位患者（或使用测试患者）→ 挂号管理办理挂号（选今日排班）→ 看到排队号
2. **doctor01 登录** → 处方开具选择该挂号 → 添加药品（可测库存不足报错）→ 提交，挂号变"已就诊"
3. **cash01 登录** → 收费退费对待收费处方收费 → 药品库存扣减 → 再退费 → 库存恢复
4. **reg01** → 挂号管理对"待就诊"挂号退号 → 号源恢复、挂号费退回
5. **admin01** → 报表查询查看各统计、CSV 导出

## 五、自动化验证

```bash
python verify_hospital.py
```

回归核心业务流：登录 → 各页面 → 挂号 → 开方 → 收费 → 退费 → 退号，全部 PASS 即健康。
（会向数据库写入一笔演示数据，如需干净数据重新执行 init_database.py 即可。）

## 六、数据库设计要点（课程要求覆盖）

- **表**：12 张（角色、用户、科室、医生、排班、患者、挂号、药品、处方、处方明细、收费、日志）
- **视图**：5 个（今日挂号、医生排班、处方明细、收费日报、医生工作量）
- **存储过程**：7 个（新增用户/医生、挂号、退号、开方、收费、退费），全部使用事务
- **触发器**：4 个（挂号/收费/建档自动写日志、有挂号的排班禁止停诊）
- **约束与索引**：唯一约束（病历号/身份证/电话/排班）、检查约束、高频查询索引
- **查询示例**：sql/06 中多表联查、分组统计、子查询

## 八、常见问题

| 问题 | 处理 |
| --- | --- |
| 页面打不开 | 确认 `python app.py` 正在运行，不要关闭运行窗口 |
| 无法连接数据库 | 运行 `python check_env.py` 定位；确认 start_mysql.bat 已启动 MySQL |
| 登录失败 | 用户名不带引号；密码默认 123456 |
| 号源已满 | 换排班或等退号；可在排班页加大号源数 |
| 排班不能停诊 | 该排班已有挂号，需先退号（触发器保护） |
| 库存不足开不了方 | 药品目录页补库存或改小数量 |
| 端口 5000 被占用 | 关闭其他占用 5000 的程序（如旧版酒店系统 Web）后重启 |
