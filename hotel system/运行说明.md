# 酒店人事一体化综合管理系统运行说明

## 〇、一分钟速览

| 步骤 | 命令 | 说明 |
| --- | --- | --- |
| 0. 启动 MySQL | 双击 `start_mysql.bat` | 免服务方式启动 MySQL（数据目录 D:\MySQLData） |
| 1. 检查环境 | `python check_env.py` | 检查 Python、依赖、MySQL、数据库状态 |
| 2. 初始化数据库 | `python init_database.py` | 一键执行 sql/01~07，建库建表灌数据 |
| 3. 安装依赖 | `python -m pip install -r python/requirements.txt` | 命令行版所需 |
| 4. 运行命令行版 | `python python/app.py` 或双击 `run_cli.bat` | 黑窗口交互菜单 |
| 5. 运行 Web 版 | `python web_app/app.py` 或双击 `run_web.bat` | 浏览器打开 http://127.0.0.1:5000 |

> 注意：本机 `pip` 命令不在 PATH，请统一使用 `python -m pip`。

## 〇·一、MySQL 安装与启动（本机已装好，可跳过）

本机已安装 **MySQL Server 8.4.9**（winget 安装，程序目录
`C:\Program Files\MySQL\MySQL Server 8.4`），采用**免服务方式**运行：

- 数据目录：`D:\MySQLData`（root 密码 `123456`，端口 `3306`，字符集 `utf8mb4`）
- **启动**：双击项目根目录 `start_mysql.bat`（每次开机后运行一次即可）
- **验证**：运行 `python check_env.py`，第 3、4 项通过即正常

> 说明：当前方案未注册为 Windows 服务，所以开机后 MySQL 不会自动启动，
> 需要双击 `start_mysql.bat` 拉起。若想改成开机自启的服务，可另行以管理员
> 运行 `install_mysql_admin.bat`（需 UAC 提权，非必须）。

## 一、文件结构

- `sql/01_create_database.sql`：创建数据库。
- `sql/02_create_tables.sql`：创建数据表、主键、外键、唯一、默认、检查约束。
- `sql/03_views.sql`：创建业务视图。
- `sql/04_procedures.sql`：创建存储过程和事务业务。
- `sql/05_triggers.sql`：创建触发器。
- `sql/06_indexes_queries.sql`：创建索引，并提供多表查询、分组统计、子查询示例。
- `sql/07_seed_data.sql`：插入测试数据并演示入住、退房、工单、薪资、离职锁定账号。
- `python/db.py`：命令行版数据库连接配置。
- `python/app.py`：命令行交互程序。
- `python/export_utils.py`：CSV 导出工具。
- `python/requirements.txt`：命令行版 Python 依赖。
- `web_app/`：Web 版（Flask），独立于命令行版，复用同一数据库。
- `init_database.py`：**一键初始化数据库脚本（推荐）**。
- `check_env.py`：**环境自检脚本（推荐）**。
- `run_cli.bat` / `run_web.bat`：**双击启动脚本**。

## 二、方式 A：一键运行（推荐，不需要 DataGrip）

### 1. 修改 MySQL 密码（如果密码不是 123456）

`init_database.py`、`check_env.py`、`python/db.py`、`web_app/db.py` 默认都使用
`root / 123456`。密码不同时，用命令行参数指定即可，不用改文件：

```bash
python init_database.py --user root --password 你的密码
python check_env.py --user root --password 你的密码
```

`python/db.py` 与 `web_app/db.py` 中的密码请直接改成你的密码，或设置环境变量
`HOTEL_DB_PASSWORD`。

### 2. 一键初始化数据库

在项目根目录执行（脚本会自动按 01→07 顺序执行，可重复运行）：

```bash
python init_database.py
```

看到 `全部脚本执行成功` 即完成，数据库 `hotel_hr_system` 已建好并灌入测试数据。

### 3. 安装 Python 依赖

```bash
python -m pip install -r python/requirements.txt
```

Web 版额外需要：

```bash
python -m pip install -r web_app/requirements.txt
```

### 4. 启动系统

**命令行版：**

```bash
cd python
python app.py
```

或直接双击项目根目录的 `run_cli.bat`。

**Web 版：**

```bash
cd web_app
python app.py
```

或直接双击项目根目录的 `run_web.bat`，看到 `Running on http://127.0.0.1:5000` 后，
用浏览器打开 http://127.0.0.1:5000 。

## 五、常见问题

### 1. MySQL 连不上

- 确认 MySQL 8.0 已安装并启动（Windows 服务名通常为 MySQL80）；
- 确认用户名/密码/端口正确（默认 root / 123456 / 3306）；
- 可用 `python check_env.py --user root --password 你的密码` 快速定位。

### 2. 提示 No module named 'mysql' / 'flask'

说明依赖未安装，执行：

```bash
python -m pip install -r python/requirements.txt
python -m pip install -r web_app/requirements.txt
```

### 3. 页面打不开

确认 `python app.py` 正在运行，不要关闭运行窗口。

### 4. 登录失败

用户名不要带引号，例如输入 `front01`，不要输入 `"front01"`。

### 5. 办理入住失败

常见原因是客房不是 `空闲` 状态，或者订单号重复。

### 6. 日期时间格式错误

日期使用 `2026-07-13`，日期时间使用 `2026-07-13 12:00:00`，薪资月份使用 `2026-07`。

## 六、课程要求覆盖情况

- 至少 12 张表：已超过 12 张，覆盖部门、岗位、员工、账号、房型、客房、客户、订单、消费、工单、考勤、薪资、日志等。
- 至少 3 个视图：已包含月度客房营收、员工月度考勤汇总、当前占用客房。
- 至少 4 个存储过程：已包含新增员工、办理入住、退房结算、批量计算薪资、发薪。
- 至少 3 个触发器：已包含离职锁定账号、退房更新房态、新增工单写日志，另加工单完成更新房态。
- 事务：入住、退房、薪资核算、发薪均使用事务。
- 查询与优化：已包含多表联查、分组统计、子查询和常用索引。
- 简易交互程序：已提供登录、基础信息管理、入住退房、考勤、薪资、报表和导出。
